# D Sun Rehab & Autism Centre — Visual redesign notes

## Design direction
The public-facing homepage has been redesigned using a warm, editorial pediatric-care direction inspired by The Children's Practice: welcoming photography, calm natural colours, expressive serif accents, generous whitespace and clear appointment/contact actions. This is an original implementation, not a copied page or source code.

## Main changes
- Replaced the logo-only hero visual with a large photographic hero and a clear family-focused message.
- Added a more editorial layout with warm cream, forest green, soft sage/lime and muted coral accents.
- Rebuilt the services area as image-led cards with expanded descriptions for the six existing therapy offerings.
- Added a child-centred approach section, four-step first-visit journey, family partnership section and clear WhatsApp/phone contact CTA.
- Restyled the public navigation and footer to match the new visual identity.
- Kept the existing About, Services, Contact and Admin routes and the centre's existing contact details.

## Image note
The homepage uses Unsplash image URLs. These require an internet connection. Before launch, replace illustrative stock photography with centre-owned photographs only where appropriate permissions and guardian consent have been obtained.

## Build note
The source files were checked for JSX syntax and balanced CSS blocks. A full Next.js production build could not be completed in this environment because dependency installation timed out. Run `npm install` and `npm run build` locally before deployment.
